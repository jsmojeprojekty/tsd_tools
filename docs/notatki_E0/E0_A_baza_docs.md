### 1.6 Konwencje nazewnicze i typy
- Nazwy tabel/kolumn: angielskie snake_case; zachowane historyczne `d0, slope_0310, iri1`; kody czujników: `m` = przed minusem (`m200` = −0,20 m), `0310` = 0,31 m (`slope_1510` = 1,51 m). Ugięcia `d_m450 … d1500` w mm-offsetach: `d200` = 200 mm od osi.
